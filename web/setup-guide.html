3 · Telegram bot token FREE

5 minute ka kaam. Reels already banti hain aur publish bhi ho rahi hain — bas post nahi ho rahi. Ye unlock karega.

  1. Apne Telegram app me search karo: @BotFather → Start.
  2. Send karo: /newbot
  3. Naam do: JaipurEst Reels
  4. Username do: jaipurest_reels_bot (unique hona chahiye, ".bot" suffixed automatic).
  5. BotFather ek token dega — 7012345678:AAH... format me. Ye hi TELEGRAM_BOT_TOKEN hai.
  6. Ab apna channel banao (agar nahi hai): Telegram me → New Channel → naam do, e.g. JaipurEst Property → public rakho.
  7. Channel kholo → admins → apne bot ko admin banao with "Post Messages" permission. Ye step chhootega to bot post nahi kar paayega.

Mujhe ye do

Tera channel private rakhna hai to bhi kaam karega — bot admin hai to post kar sakta hai. Channel ID @name se shuru hoti hai, private channel me -100… se. Jo bhi mila wahi de de.

5 · Token mujhe kaise dein — tez raasta vs safe raasta

⚠️ Chat me token paste mat karna agar possible na ho. Jo bhi chat me likhta hai, wo us session ke history me chala jaata hai — aur wo log baad me kisi aur ko dikh sakte hain. Meta ka token se tere WhatsApp number tak message bheja ja sakta hai. Domain aur LLM key safe hain, par META_TOKEN aur TELEGRAM_BOT_TOKEN sensitive hain. Safer: neeche wala 30-second tarika hai — tu sirf ek command chala, mujhe token dikhai hi nahi deta.

Option A — SAFE (recommended, 30 sec per secret)

Har secret ke liye ek command. Ye command khud puchegi aur tu type karega — meri taraf se text nahi jayega. Bas Enter daba dena hai paste karne ke baad (screen dikhayega, koi nahi padhega).

cd C:\Users\ohpum\jaipur-realty\leadbox
npx wrangler secret put META_TOKEN
npx wrangler secret put META_PHONE_ID
npx wrangler secret put VERIFY_TOKEN
Ye baat samajh le, taaki galti na ho: leadbox folder me chalega, jaipurest-wa nahi. Ye meri galti-prone jagah hai — wo Workers vars use karte hain (secret nahi). Main deploy ke baad ek test message bhejkar confirm karunga ki token sach me kaam kar raha hai. Agar nahi, to tumhe bata dunga ki wrangler.toml me [vars] add karna hai — wo mera kaam hai, tera nahi.

Option B — simple (agar Option A confuse kare)

Bas mujhe chat me likh do, main khud deploy kar dunga. Fast hai, lekin token history me rahega. Domain aur LLM key ke liye ye bilkul theek hai.

Ya bilkul simple — file me de

Notepad me likh de aur mujhe bata "file ready hai", main uthata hoon. Phir wo file turant delete kar dena (chhota sa note text editor se bana le, git me kabhi commit nahi hoga).
